#+TITLE: Xenolith
#+SUBTITLE: An "opinionated" Autolith distribution
#+STARTUP: content

Xenolith is to [[https://github.com/lambda-symbolics/autolith][Autolith]] what Doom Emacs and
Spacemacs are to Emacs, a curated configuration layer that supplies
presentation, defaults, and commands without forking the upstream project.

#+CAPTION: The Xenolith look: fullscreen frame, tool blocks, inline diffs,
#+CAPTION: and the status band above the composer.
[[file:example.png]]

* Notable features

- *Helix modality*: normal, select, insert, and command modes with Helix's word
  motions in the composer; the mode shows in the status band.
- *The look*: an █[PROVIDER CREDENTIAL REDACTED]█-inspired composed terminal over a gruvbox palette: a fullscreen
  frame, filled tool, diff, and reasoning surfaces, a composer with an effort bar.
- *Context budgeting* (opt-in): bounds a long child run by context fill rather
  than queue depth, handing the model one instruction per phase.

* Install

#+BEGIN_SRC sh
nix profile install github:coldcatallactics/xenolith
xenolith
#+END_SRC

On NixOS, add =inputs.xenolith.url = "github:coldcatallactics/xenolith";=
and the module to the host:

#+BEGIN_SRC nix
modules = [
  inputs.xenolith.nixosModules.default
  { programs.xenolith.enable = true; }
];
#+END_SRC

With Home Manager, in a module where =inputs= is in scope:

#+BEGIN_SRC nix
{
  imports = [ inputs.xenolith.homeManagerModules.default ];
  programs.xenolith.enable = true;
}
#+END_SRC

Both install the =xenolith= launcher, which carries its own site tree.

Without Nix, with =autolith= on =PATH= (upstream builds from source with
=./script/bootstrap= and Quicklisp), clone the tree and use its site layer:

#+BEGIN_SRC sh
git clone https://github.com/coldcatallactics/xenolith
AUTOLITH_SITE_CONFIG_ROOT=$PWD/xenolith/site autolith
#+END_SRC

The flake packages =site/= and a =xenolith= launcher that exports
=AUTOLITH_SITE_CONFIG_ROOT= and execs the pinned upstream binary.
